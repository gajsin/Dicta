**Dicta** — быстрое и легковесное настольное приложение для голосового ввода текста в Windows с компактным плавающим индикатором и интеллектуальной коррекцией через нейросети.

Нажмите горячую клавишу в любом приложении, надиктуйте мысль — и готовый отредактированный текст мгновенно появится в активном поле ввода.

---

## Возможности

- **Глобальный хоткей и мгновенный ввод**: активация записи одной клавишей (по умолчанию `F9`), `Esc` для быстрой отмены, автоматическая вставка расшифрованного текста через системный буфер.
- **Интеллектуальная постобработка текста**: встроенная коррекция пунктуации, капитализации и удаление слов-паразитов с помощью LLM. Доступны стили: *Сырой*, *Минимальный*, *Сбалансированный*, *Деловой*.
- **Поддержка популярных провайдеров**: работа со своими API-ключами через Groq (сверхбыстрый Whisper), OpenAI, OpenRouter или Polza.ai.
- **Плавающий оверлей (HUD)**: минималистичный виджет поверх всех окон с живой анимацией громкости микрофона.
- **Локальная история**: поиск по всем сделанным записям, просмотр исходного и обработанного текста, копирование в один клик.
- **Персонализация интерфейса**: светлая, тёмная и системная темы, выбор акцентных цветов, русская и английская локализации.
- **Работа в фоне**: сворачивание в системный трей Windows с возможностью быстрого вызова настроек и выхода.
- **Иконки по теме Windows**: чёрные в светлой теме, белые в тёмной. При установке и запуске обновляются ярлыки; пока Dicta работает, включая трей, смена темы обновляет их и значок панели задач.

## Установка и запуск

1. Перейдите в раздел [**Releases**](https://github.com/gajsin/dicta/releases) и скачайте актуальный установщик `Dicta_0.3.1_x64-setup.exe`.
2. Запустите установку (при необходимости установщик автоматически настроит среду WebView2).
3. Откройте окно Dicta:
   - В разделе **Провайдеры** введите API-ключ выбранного сервиса (например, Groq или OpenAI).
   - В разделе **Диктовка** выберите микрофон и настройте удобную комбинацию клавиш.
4. Сверните окно в трей. Нажмите `F9` в любом месте (Telegram, браузер, редактор кода, Word) и говорите!

---

## Конфиденциальность

- Все настройки и API-ключи хранятся исключительно локально на вашем устройстве в `%APPDATA%\Dicta\settings.json`.
- Приложение не содержит сторонних аналитических трекеров или скрытой телеметрии.
- Аудиозапись хранится только в оперативной памяти во время распознавания и отправляется напрямую в выбранный вами API.
- Историю диктовок можно в любой момент отключить или очистить в настройках.

## Разработка и сборка из исходников

### Требования к окружению
- **Windows 10 / 11** (x64)
- **Node.js** `>= 22.12.0`
- **Rust** (stable toolchain с MSVC target)
- **Microsoft C++ Build Tools**
- **WebView2 Runtime**

### Установка и запуск dev-сервера

```bash
# 1. Клонирование репозитория
git clone https://github.com/gajsin/dicta.git
cd dicta

# 2. Установка зависимостей
npm install

# 3. Запуск приложения в режиме разработки
npm run tauri dev
```

### Проверка кода и сборка релиза

```bash
# Проверка типов и сборки фронтенда
npm run check

# Проверка Rust-бэкенда
npm run lint
npm run format:check

# Сборка готового инсталлятора Windows (NSIS .exe)
npm run tauri build
```

Готовый файл установщика будет сформирован в директории `src-tauri/target/release/bundle/nsis/`.

## Архитектура проекта

- `src/` — клиентская часть на **Svelte 5 (Runes)** и TypeScript:
  - `src/lib/components/` — главное окно, оверлей виджета, визуализатор звука, настройки;
  - `src/lib/recording/` — управление состоянием аудиозаписи;
  - `src/lib/i18n/` — двуязычная локализация (RU / EN);
  - `src/lib/history/` — хранилище истории диктовок.
- `src-tauri/` — нативный бэкенд на **Rust**:
  - `src/audio/` — захват системного микрофона через `cpal`, ресемплинг (`rubato`), расчет уровней и кодирование WAV;
  - `src/transcription/` — отправка запросов в STT- и LLM-сервисы;
  - `src/commands/` — IPC-обработчики команд между окном и системой;
  - `src/window_overlay.rs` — прозрачный компактный оверлей на Win32 API.
